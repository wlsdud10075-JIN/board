## board_region_inspection — 지역 검차 안내
- 수신자: 그 지역×날짜 배정 검차원(`InspectionAssignment`).
- 변수: `#{지역}` · `#{건수}` · `#{차량목록}`(가변, 개행 구분 차량번호 목록 — 길이 검수 주의).
- 유형: 기본형(선택안함). title 미사용.

```
[사내 업무용] 검차 배정 안내 #{지역}

담당자님, 배정된 지역에 검차가 접수되어 안내드립니다.

■ 지역: #{지역}
■ 검차 대상: #{건수}대
#{차량목록}

사내 업무 시스템(board)에서 검차 결과를 등록해 주세요.
```

예시 렌더(#{차량목록} = 개행 목록):
```
[사내 업무용] 검차 배정 안내 경기 화성

담당자님, 배정된 지역에 검차가 접수되어 안내드립니다.

■ 지역: 경기 화성
■ 검차 대상: 2대
12가3456
34나5678

사내 업무 시스템(board)에서 검차 결과를 등록해 주세요.
```

## board_forward_ready — 사진/영상 완료·전달대기 (→ 영업담당자)
- 수신자: 그 매물 작성 영업(`purchase_listings.created_by_user_id`).
- 트리거: ssancar 자동전이(draft→inspected/전달대기) 직후. 변수: `#{차량번호}`.
- 유형: 기본형. title 미사용.

```
[사내 업무용] 전달 대기 안내 #{차량번호}

담당자님, 등록하신 매물 #{차량번호}의 사진/영상 업로드가 완료되어 바이어 전달 대기 상태입니다.

사내 업무 시스템(board)에서 확인 후 바이어에게 전달해 주세요.
```

## 탁송 배차 요청 `board_transport_request` (2026-11-12 기획 — BizM 제출 대기, 코드 미등록)

- 템플릿명 「탁송 배차 요청」 · BA · 카테고리 008002 · 변수 `#{요청회사}` `#{차량번호}` `#{주소}` `#{요청일시}` · WL 버튼 1개 「배차 확인」 = `{board 도메인}/a/transport/#{url}`.
